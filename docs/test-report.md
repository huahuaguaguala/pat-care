# 2. 初始化数据库（密码已使用真实BCrypt哈希）
mysql -uroot -proot < pet-care-server/src/main/resources/schema.sql

# 3. 运行测试（店员密码: 123456）
cd pet-care-server

## 四、已知限制与后续改进

| 限制 | 影响 | 改进计划 |
|------|------|---------|
| 优惠券秒杀测试需 Redis 运行 | 离线CI环境会失败 | 添加 TestContainers 或 Embedded Redis |
| WebSocket 推送未自动化测试 | 实时推送逻辑靠手工验证 | 集成 Spring WebSocketTest 客户端 |
| 无 Service 层分离 | 控制器直接调用 Mapper | 后续重构提取 Service 层 + 单元测试 |

---

## 五、测试结论

10 个集成测试用例覆盖了 MVP 的 4 个核心链路：

- ✅ **认证链路**：微信登录注册 + 账号密码登录(BCrypt) + JWT 签发/验证 + 拦截器
- ✅ **业务链路**：宠物 CRUD + 订单创建→支付→状态流转 + 角色数据隔离
- ✅ **Redis 特性**：BitMap 签到(含重复拦截) + ZSet 排行榜 + Lua 秒杀
- ✅ **权限边界**：未登录 401 + 公开接口豁免 + 角色操作限制
