# 爪爪护理 — 宠物护理店 O2O 驻店系统

> 借鉴苍穹外卖（全栈广度）与黑马点评（Redis 深度），
> 三角色（宠物主 / 店员 / 店长）、微信小程序 + Vue3 管理后台的宠物护理 O2O 系统。

## 技术栈

Spring Boot + MyBatis-Plus + MySQL + Redis + JWT + WebSocket + 微信小程序 + Vue3 + Element Plus

## 快速开始

```bash
docker-compose up -d   # 启动 MySQL + Redis + Nginx
# 启动后端 Spring Boot 应用
# 微信开发者工具打开 pet-care-miniapp/
# npm run dev 启动管理后台
```
